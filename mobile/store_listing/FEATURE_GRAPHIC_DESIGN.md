# Feature Graphic Design Specification

## 📐 Dimensions & Format
- **Size:** 1024 x 500 pixels
- **Format:** PNG or JPG

## 🛠️ Tools & How to Create

### Option A: Canva (Easiest - Recommended)

1. **Setup:**
   - Go to https://canva.com
   - Create custom size: **1024 x 500 px**
   - Start with blank canvas

2. **Background:**
   - Click "Elements" → "Shapes" → Rectangle
   - Resize to fill canvas (1024x500)
   - Click shape → "Color" → Select gradient
   - Choose blue gradient or custom colors

3. **Add App Icon:**
   - Click "Uploads" → Upload your `icon.png`
   - Drag to canvas
   - Resize to ~128-150px
   - Position on left side

4. **Add Text:**
   - Click "Text" → "Add heading"
   - Type "BLACK EAGLE"
   - Select bold font (Montserrat Bold, Anton, Bebas Neue)
   - Size: 48-52pt
   - Color: White
   - Position: center-left

5. **Add Subtitle:**
   - Click "Text" → "Add subheading"
   - Type "Professional Dog Management"
   - Font: Montserrat or Roboto
   - Size: 24pt
   - Color: Light gray/white
   - Position below main text

6. **Add Icons:**
   - Click "Elements" → Search "dog icon"
   - Add 3-4 icons representing features
   - Make them same size (~64px)
   - Space evenly on right side
   - Change color to match theme

7. **Final Touches:**
   - Add subtle shadow to text (Effects → Shadow)
   - Adjust spacing and alignment
   - Preview at different zoom levels

8. **Export:**
   - Click "Download"
   - File type: PNG
   - Quality: Highest
   - Download (will be 1024x500)

---

### Option B: Figma (Professional)

1. **Setup:**
   - Open Figma (https://figma.com)
   - Create new design file
   - Frame: 1024 x 500

2. **Background Layer:**
   - Rectangle tool (R)
   - Draw full-size rectangle
   - Fill: Linear gradient
   - Gradient stops: #1565C0 → #0D47A1

3. **Import Icon:**
   - Drag `icon.png` into Figma
   - Resize: 128 x 128
   - Position: X: 60, Y: 186 (centered vertically)

4. **Text Layers:**
   - Text tool (T)
   - "BLACK EAGLE" 
     - Font: Inter Bold or SF Pro Bold
     - Size: 48px
     - Color: #FFFFFF
     - Position: X: 220, Y: 180
   
   - "Professional Dog Management"
     - Font: Inter Regular
     - Size: 24px
     - Color: #E3F2FD
     - Position: X: 220, Y: 240

5. **Feature Icons:**
   - Use Iconify plugin or import SVGs
   - Icons: dog, medical, chart, money
   - Size: 48 x 48
   - Color: #FFA726
   - Spacing: 20px between
   - Position: Right side, centered

6. **Effects:**
   - Select text → Add effect → Drop shadow
   - X: 0, Y: 2, Blur: 4, Color: #000000 20%

7. **Export:**
   - Select frame
   - Export settings → PNG
   - 1x scale (1024x500)
   - Export

---

### Option C: Photoshop (Advanced)

1. **New Document:**
   - File → New
   - Width: 1024px, Height: 500px
   - Resolution: 72 PPI
   - Color Mode: RGB
   - Background: White

2. **Gradient Background:**
   - Gradient tool (G)
   - Colors: #1565C0 to #0D47A1
   - Style: Linear, Left to right
   - Draw across canvas

3. **Import Icon:**
   - File → Place Embedded
   - Select `icon.png`
   - Resize to 128 x 128
   - Position on left

4. **Add Text:**
   - Text tool (T)
   - Type "BLACK EAGLE"
   - Font: Arial Black or custom
   - Size: 48pt
   - Color: White
   - Layer style: Drop shadow (2px blur)

5. **Add More Elements:**
   - Import or create feature icons
   - Add subtitle text
   - Add bullet points or separators

6. **Save:**
   - File → Export → Export As
   - Format: PNG-24
   - Quality: 100%
   - Save

## 💡 Pro Tips

1. **Keep it simple** - Don't overcrowd with too many elements
2. **High contrast** - Ensure text is readable on background
3. **Test at scale** - View at 50% to see how it looks small
4. **Brand consistency** - Use same colors as app icon
5. **Mobile-first** - Many users browse on mobile, test there
6. **Stand out** - Look at competitor graphics, be different
7. **Avoid clichés** - Generic dog photos won't help, be unique
8. **Professional fonts** - Avoid overly decorative fonts
9. **White space** - Don't fill every pixel, give elements room
10. **Multiple versions** - Create 2-3 options, choose best
