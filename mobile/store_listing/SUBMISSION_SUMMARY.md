## ⏱️ Build Commands

### Clean Build
```bash
cd mobile
flutter clean
flutter pub get
flutter build apk --release
```

### Split APKs (smaller size)
```bash
flutter build apk --split-per-abi --release
```

### Check APK Size (PowerShell)
```powershell
Get-ChildItem build\app\outputs\flutter-apk\app-release.apk | Select-Object Name, @{Name="SizeMB";Expression={[math]::Round($_.Length / 1MB, 2)}}
```

### Install on Device
```bash
adb install build/app/outputs/flutter-apk/app-release.apk
```

## 🆘 If Rejected

**Common reasons and fixes:**

1. **Missing Privacy Policy**
   - Host at public URL
   - Update submission with correct URL

2. **Poor Quality Graphics**
   - Recreate at correct dimensions
   - Use high-resolution images
   - Follow design guidelines

3. **Misleading Description**
   - Ensure description matches features
   - Remove exaggerated claims
   - Be honest and accurate

4. **APK Issues**
   - Rebuild APK
   - Test thoroughly before resubmission
   - Check for crashes

5. **Permissions Not Explained**
   - Add clear explanations
   - Justify each permission
   - Remove unnecessary permissions

**If rejected:** Fix issues and resubmit within 24-48 hours
