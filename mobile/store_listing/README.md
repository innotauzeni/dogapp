## 🚀 Quick Start (3 Steps)

### Step 1: Build Release APK
```bash
cd mobile
flutter clean
flutter pub get
flutter build apk --release
```
📦 Output: `build/app/outputs/flutter-apk/app-release.apk`

### Step 2: Prepare Graphics
- [ ] App Icon: `assets/icon.png` (512x512) ✓ Ready
- [ ] Feature Graphic: Create 1024x500 banner (see FEATURE_GRAPHIC_DESIGN.md)
- [ ] Screenshots: Capture 2-8 screenshots (see SCREENSHOT_GUIDE.md)

### Step 3: Submit to APKPure
1. Login: https://developer.apkpure.com/
2. Upload APK
3. Upload graphics
4. Fill in details from APKPURE_SUBMISSION_GUIDE.md
5. Submit for review

## 🆘 Common Issues & Solutions

### "Build failed"
- Run `flutter clean` then rebuild
- Check Java version (need JDK 17+)
- See BUILD_INSTRUCTIONS.md troubleshooting

### "Keystore error"
- Verify `key.properties` file exists
- Check keystore path is correct
- See BUILD_INSTRUCTIONS.md Step 1

### "APK too large"
- Use split APKs: `flutter build apk --split-per-abi`
- Current size should be 15-50MB (well under 100MB limit)

### "Can't capture screenshots"
- Use emulator if device won't work
- Try ADB command method
- See SCREENSHOT_GUIDE.md Option C

### "Feature graphic rejected"
- Ensure exactly 1024x500 pixels
- Check file size under 1MB
- No misleading content
- See FEATURE_GRAPHIC_DESIGN.md
