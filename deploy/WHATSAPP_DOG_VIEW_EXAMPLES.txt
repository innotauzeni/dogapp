QUICK REFERENCE - View Command Data Sections
================================================================================

📋 BASIC INFO
  Name, Breed, Gender
  DOB (with age calculation)
  Microchip number
  Color/Markings

📊 STATUS
  Current status (Active/Deployed/Retired/Other)
  Owner name
  Assigned handler
  Current location/branch

💉 VACCINATIONS
  Vaccine name
  Last vaccination date
  Status (✅ Current, ⚠️ Due soon, 🔴 Overdue)
  Next due date

👨‍👩‍👧‍👦 FAMILY
  Sire (father) - name & ID
  Dam (mother) - name & ID
  Offspring count
  Litter info if applicable

❤️ RECENT ACTIVITY (Last 5)
  Activity type (Feeding, Vaccination, Mating, Birth, etc.)
  Date & time
  Notes if applicable

================================================================================
FOLLOWING ACTIONS AFTER VIEW
================================================================================

After viewing a dog, you can:

1. RECORD ACTIVITY:
   record 1 feeding Good appetite
   record 1 vaccine Rabies booster
   record 1 mating Mated with Luna

2. CHECK VACCINES:
   vaccine
   (Shows all dogs needing vaccinations)

3. SEE BREEDING INFO:
   breeding
   (Shows all active matings and litters)

4. VIEW ANOTHER DOG:
   view 2
   detail 3

5. GET QUICK STATS:
   status
   (Shows dashboard summary)

================================================================================
TIPS FOR USING VIEW COMMAND
================================================================================

✅ Use before recording activities to confirm dog ID
✅ Check vaccination dates to stay on top of schedules
✅ Monitor recent activities to track dog's health
✅ View family info to manage breeding records
✅ Share screenshots with veterinarian if needed
✅ Use dog ID from list (dogs command) if unsure

================================================================================
ERROR HANDLING
================================================================================

If dog ID is invalid:
  INPUT: view 999
  OUTPUT: Dog not found. Use 'dogs' to see valid IDs

If format is wrong:
  INPUT: view
  OUTPUT: Usage: view [dogId] or detail [dogId]
          Example: view 1

If dog has no activities:
  OUTPUT: Shows "No recent activity" instead of list
